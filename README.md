# ONE SCHOOL SOLUTION (OS²) – Official Landing Page

> **Unified School Management Ecosystem Connecting Schools, Parents, Teachers, and Administrators.**

Welcome to the official repository for the **ONE SCHOOL SOLUTION (OS²)** website. This repository contains the complete responsive, high-performance landing page featuring Apple-style cinematic fluid depth, interactive 3D hero carousel, atmospheric time-of-day sky transitions, Google Form demo modal integration, and direct communication channels.

## ✨ Features

- **Cinematic Hero Section**: 
  - Dynamic time-of-day lighting engine (Morning, Afternoon, Evening, Night).
  - Volumetric cloud simulation and parallax scroll curtain.
  - Interactive 3D orbiting feature carousel with roll-to-front animation and detailed feature popups.
- **Embedded Google Form Integration**:
  - One-click "Book Demo" and "Click to Join" buttons open an embedded Google Form modal without leaving the landing page.

## 🛠️ Tech Stack

- **Frontend**: Pure Semantic HTML5, Modular CSS3 (Custom Properties, Flexbox, CSS Grid, Glassmorphism), Vanilla ES6+ JavaScript.
- **Backend**: Node.js (`http`, `fs`, `nodemailer`).
- **Icons & Typography**: Font Awesome 6 Pro / Free, SF Pro Display & System UI typography.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone <your-repository-url>
cd "school landing"
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Local Server
```bash
npm start
```
The website will be live at:
👉 **http://localhost:3000**
